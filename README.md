For Developer

1. When building and deploying to production, always include the .env file in the project root before building. You can delete the .env file from the project afterward.

2. Build and deploy from the development branch; it is not necessary to switch to the production branch.

Commands:
- npm run build
- npm run deploy

3. The contact page may sometimes appear not to work because the .env variable takes time to load and communicate with Formspree. Wait a moment and then check if it is working.
